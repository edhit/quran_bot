# Личный учитель Корана в Telegram

Бот для хифза вдолгую: даёт новое, гоняет повторение по расписанию, слушает твою
запись и разбирает ошибки, считает — укладываешься ли ты в свой срок.

Работает на Cloudflare Workers: без сервера, без Docker, почти бесплатно.

---

## Что он делает

**Заучивание.** Считает, сколько страниц в неделю тебе нужно, чтобы закончить за
твой срок, и каждое утро выдаёт ровно столько нового. Единица учёта — страница
мусхафа, а не аят: хафиз держит в памяти страницу целиком.

**Повторение.** Три потока, как в классической мединской схеме:

| Поток | Что это | Как часто |
|---|---|---|
| `حفظ جديد` | новое заучивание | каждый день |
| `مراجعة قريبة` | всё, выученное за последние 30 дней | каждый день |
| `مراجعة بعيدة` | всё остальное, по кругу | весь объём за ~30 дней |

Внутри дальнего потока страницы идут не подряд, а по прочности: первой приходит
та, что сильнее выветрилась. Прочность считается по кривой забывания
`R(t) = exp(-t/S)`, где `S` растягивается после чистого чтения и резко сжимается
после срыва.

**Проверка голосом.** Записываешь чтение по памяти → Whisper расшифровывает →
бот пословно сверяет с мусхафом → Claude объясняет каждую ошибку: что
пропустил, где перепутал окончание, а главное — на какой похожий аят ты съехал
(муташабихат). Все такие съезды копятся в `/mistakes`.

**Понимание.** Перевод, тафсир, аудио Хусари — по любому аяту. Пословный разбор
с корнями и грамматикой, слова из того, что ты сейчас учишь, попадают в словарь
с собственным повторением.

**Дисциплина.** Серия дней, счётчик долга, вечерняя проверка с нарастающим
тоном, пятничный отчёт. Отчёт можно автоматически слать другу или преподавателю
(`PARTNER_CHAT_ID`) — это и есть та самая мухасаба, ради которой «стыдно».

## Чего он НЕ делает — читай обязательно

**Таджвид не проверяется.** Распознавание речи приводит звук к орфографии:
мадд, гунна, ихфа, махрадж туда просто не доходят. Бот честно молчит об этом и
никогда не пишет про таджвид. Для таджвида нужен живой шейх — бот его не
заменяет и не пытается.

**Распознавание знает Коран и склонно «дочитывать» за тебя.** Whisper обучен на
записях чтения и иногда выдаёт правильный вариант там, где ты ошибся. Поэтому:

* бот не передаёт распознавателю эталон подсказкой (иначе он замажет ровно те
  ошибки, которые мы ищем);
* расхождения в одну букву помечаются как шум и не идут тебе в минус;
* показатель «93%» — это оценка, а не приговор. Тенденция по неделям
  информативнее одной цифры.

Что ловится надёжно: пропущенные слова, лишние слова, подмена слова, сбитый
порядок, переход на другой аят. Этого достаточно, чтобы найти дыры в хифзе.

## Установка

Нужны: аккаунт Cloudflare, токен Telegram-бота от [@BotFather](https://t.me/BotFather),
ключ [Anthropic API](https://console.anthropic.com), Node.js 18+.

### 1. Код и зависимости

```bash
git clone https://github.com/edhit/quran_bot
cd quran_bot
npm install
npx wrangler login
```

### 2. База

```bash
npm run db:create           # выведет database_id — вставь его в wrangler.toml
npm run db:migrate
```

Если в ответ приходит `A database with that name already exists`, значит база
уже заведена раньше — второй раз создавать её не надо. Узнай id существующей:

```bash
npm run db:id               # строка uuid в выводе и есть database_id
```

### 3. Текст Корана

Скачивается один раз с твоей машины и заливается в твою базу. Скрипт проверяет
результат (114 сур, 6236 аятов, 604 страницы, 30 джузов) и не запишет файл,
если источник отдал неполные данные.

```bash
npm run quran:fetch
npm run quran:load
```

В репозитории лежит только арабский текст. Переводы и тафсир бот берёт из
открытого API по мере надобности и кэширует в твоей же базе — так ты
пользуешься источником напрямую.

### 4. Секреты

```bash
npx wrangler secret put TELEGRAM_TOKEN
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET   # любая длинная случайная строка
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put OWNER_ID                  # твой telegram id — чтобы бот был только твой
```

Свой id узнаёшь у [@userinfobot](https://t.me/userinfobot).

### 5. Деплой и вебхук

```bash
npm run deploy

TELEGRAM_TOKEN=... \
TELEGRAM_WEBHOOK_SECRET=... \
WORKER_URL=https://quran-bot.<твой-поддомен>.workers.dev \
  npm run hook:set
```

Проверка: `curl https://quran-bot.<поддомен>.workers.dev/health` — должно вернуть
`{"ok":true,"ayat":6236}`.

### 6. Первый запуск

Напиши боту `/start`. Он задаст семь вопросов: имя, текущее место (например
`6:71`), часовой пояс, срок, дней в неделю, час плана, час проверки. После этого
всё до твоего места помечается выученным и встаёт в очередь повторения, а бот
показывает нужный темп.

### 7. Источники перевода и тафсира

`TRANSLATION_ID` и `TAFSIR_ID` в `wrangler.toml` стоят по умолчанию, но их стоит
сверить: команда `/sources` выведет список доступных на русском с точными id.
Поставь нужные и сделай `npm run deploy`.

Чтец проверяется командой `/reciter` — она реально дёргает файл на everyayah.com
и говорит, доступна ли папка.

## Сколько это стоит

| Что | Сколько |
|---|---|
| Cloudflare Workers | бесплатно на Free-плане; $5/мес на Paid (советую — лимиты CPU) |
| D1 (база) | бесплатно в этих объёмах |
| Workers AI (Whisper) | есть бесплатная суточная квота; при 3–5 проверках в день упираться не будешь |
| Anthropic API | основная статья расхода |

Одна проверка отрывка на `claude-opus-5` с высоким effort — примерно **5–10
центов** (разбор ошибок идёт с рассуждением, оно и стоит). Три проверки в день —
порядка **$5–10 в месяц**.

Если дорого, есть три ручки в `wrangler.toml`, по убыванию влияния:

```toml
CLAUDE_EFFORT = "low"          # раза в три дешевле, разбор короче
CLAUDE_MODEL  = "claude-sonnet-5"   # ещё в 2,5 раза дешевле за токен
CLAUDE_MODEL  = "claude-haiku-4-5"  # самый дешёвый, разбор заметно площе
```

Пословный разбор аята (`/words`) стоит денег один раз: результат кэшируется
навсегда. Проверки без единой ошибки вообще не идут в модель — там хватает
пословного сравнения.

## Команды

```
/plan       план на сегодня
/check      проверить чтение голосом
/ayah 6:71  текст, перевод, аудио, тафсир
/words 6:71 разбор слов с корнями
/grammar    иʿраб аята
/drill      карточки арабских слов
/stats      прогресс, темп, прогноз, слабые места
/mistakes   муташабихат — где ты путаешься
/settings   темп, срок, время напоминаний
/sources    список переводов и тафсиров с id
/reciter    сменить чтеца
/pause      пауза без потери прогресса
```

## Как устроен код

```
src/
  index.ts       вход: вебхук + крон
  router.ts      команды, кнопки, голосовые
  onboarding.ts  мастер настройки (состояние в БД, Worker без памяти)
  plan.ts        сборка плана на день, закрытие заданий
  srs.ts         кривая забывания, интервалы, расчёт темпа
  arabic.ts      нормализация арабского и пословное выравнивание (LCS)
  check.ts       Whisper → сравнение → разбор от Claude
  claude.ts      Messages API: strict tool use, кэш промпта, fallback
  quran.ts       перевод, тафсир, аудио
  vocab.ts       разбор слов, словарь, SM-2
  stats.ts       прогресс и прогноз
  cron.ts        утренний план, вечерняя проверка, пятничный отчёт
  db.ts          доступ к D1
```

Методика и формулы расписаны в [`docs/METHOD.md`](docs/METHOD.md).

## Если что-то сломалось

**Бот молчит.** `npm run hook:info` — посмотри `last_error_message`.
Логи: `npx wrangler tail`.

**`/plan` говорит, что база пустая.** Не залит текст: `npm run quran:fetch && npm run quran:load`.

**Перевод не приходит.** Скорее всего сменился id источника — `/sources`.

**`npm run quran:fetch` падает на проверке.** Источник отдал неполные данные.
Попробуй другой: `node scripts/seed-quran.mjs --api-base <url>`.
